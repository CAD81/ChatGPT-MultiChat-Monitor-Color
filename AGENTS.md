# Agentenanweisungen

Vor jeder Bearbeitung **GITHUB_COST_RULES.md** lesen. Dessen verbindliche Kosten-, Sichtbarkeits- und Release-only-Regeln haben Vorrang vor älteren Anweisungen. GitHub Actions nur für ausdrücklich beauftragte Releases; Entwicklung, Tests und Prüfungen außerhalb GitHub Actions. Remote-Stand, fremde PRs/Commits und `.github/workflows/` vor GitHub-Änderungen prüfen. Ohne vollständige Pflichtprüfungen keine Erfolgs-/Mergefreigabe behaupten.
